# 💫 About Me:
Amrinder Singh is a Computer Science and Engineering undergraduate specializing in Cybersecurity and Machine Learning, with strong hands-on experience in AI system architecture, local LLM deployment, computer vision, and intelligent software development. Proficient in Python, C/C++, Java, OpenCV, PyQt/PySide, MongoDB, Linux, and modern AI frameworks, he focuses on building secure, scalable, and high-performance applications.

He has developed projects including Gemma-powered AI assistants using Ollama, face recognition attendance systems, real-time network traffic analyzers, computer vision applications, and interactive GUI-based security tools. His expertise spans LLM integration, AI agent architectures, API development, data pipelines, system optimization, and security-aware software engineering.

Currently, he is actively exploring LLM orchestration, AI agents, Retrieval-Augmented Generation (RAG), computer vision, ethical hacking, malware analysis fundamentals, and AI visualization systems. Passionate about creating next-generation intelligent systems, he aims to combine AI, cybersecurity, and software engineering to develop robust, privacy-preserving, and efficient solutions that address real-world challenges.
